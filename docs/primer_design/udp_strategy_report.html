自建 UDP 筛选流程

从 960 条自建序列出发，选出 96 对（前 48 对为核心 48 组），最后一版整管实测没有 C 级。本页记录每个阶段做了什么、C 级是怎么消失的，以及 A 级还能不能再提高。

评价的是什么

每个管（一个 i5 + 一个 i7，加上 33 条寡核苷酸展开成的 198 条引物）在 58 °C、50 mM Na⁺、2 mM Mg²⁺、250 nM 下，用 primer3 算全部两两异源二聚体 ΔG 和 3′端稳定性。

这些阈值是我定的经验阈值。没有无尾巴基线以外的实验标定（无尾巴时最差约 −5.7 / −3.8）。

分阶段流程

  1. 基线：Illumina 384 对原配对

    先把 Illumina UDP 原样配对评一遍，作为对照。371 个有效管里 A 86（23%）、B 126、C 159（43%）。挑选后的 96 管可以做到 0 个 C，A 约 34–40 个。

  2. 第一阶段：960 条序列各自评估

    自建 960 条 10 nt 序列（U001–U960，每条都可当 i5 或 i7）。单条规则：GC 4–6、无 ≥3 同聚物、无二核苷酸重复 ≥3 次、无 GGGG、不含接头 6-mer、非回文，且与 Illumina 的 384 对不同。再分别和上游或下游引物算单侧二聚体和发夹。

    输入 960 条序列 + 33 条寡核苷酸输出 每条序列的 FF / RR / 发夹代价

  3. 第二阶段：144 个 i5 + 144 个 i7 候选池

    在池内就保证：任意两条编辑距离 ≥4；跨类（i5 对 rc(i7)）反向互补编辑距离 ≥3；每周期组成可达标。多留一些冗余，给后面挑选空间。

    输入 960 条 + 单条代价输出 144 × 144 候选池

  4. 第三阶段：正向 × 反向的热点相互作用

    i5 的影响只在正向引物之间，i7 只在反向引物之间，真正依赖配对的是 i5 × i7 的正反向相互作用。只有约 6.5% 的引物对会出问题，所以只对“热点引物对”（先 38 对，后补到 57 对）精确计算，20736 个组合，每个约 1.24 秒，差到不可能是 A/B 时提前停止。

    输入 候选池 + 热点引物对输出 每个 i5 × i7 组合的预测等级

  5. 第四阶段：选 96 对并配对

    模拟退火。能量 = 等级代价（A 0、B 3、C 30）加上每周期配色越界的惩罚（权重 1000）。核心 48 的权重翻倍，并且核心 48 自己也要满足每周期组成。

    输出 96 对预测等级

  6. 第五阶段：整管实测

    对选出的每一个管算完整的 198 × 198 异源二聚体和 3′端矩阵，包括热点代理没有覆盖的引物对。这一步才给出可以信的等级。

  7. 修复循环：按实测改

    每一轮实测都发现代理漏掉的管。修法有三种，按顺序用：

    • 实测覆盖：已测过的组合直接用实测等级代替预测，后面的重选不再碰坏的。
    • 禁用序列：如果某条 i7 在几乎所有搭配里都是 C（例如 U864 与反向引物 A4-R.2、A5-R.1 的 3′端稳定性是 −5.78），整条禁用。
    • 换配对：每周期配色只取决于 i5 集合和 i7 集合，和谁配谁无关。所以 C 管可以和同组里别的管互换 i7，序列集合不变，约束不受影响。每个 C 管试 8 个交换对象，把交换后的两个管都实测，挑两个都不低于 B 的。

  8. 脱靶

    尾巴在 5′端，不会产生新的 3′种子位点。对基因特异部分 ≤5 个错配的已知位点，加上 5′侧 10 nt 的基因组侧翼，重新算带尾巴的全长错配数。

三个原因

  • C 管是局部问题。每个 C 管通常由一两个具体的引物对（例如一条 i7 与某条反向引物）造成，不是整个池都差。所以可以绕开：禁用一条 i7，或换一下配对。
  • 换配对不改变任何序列约束。每周期配色、编辑距离、反向互补只取决于序列集合。把 R004 的 i7 和另一个管互换后，两个管都实测不低于 B，约束照旧满足。
  • 代价函数把 C 压得很重（C 为 30，B 为 3），重选时 C 几乎不会被选中；加上“实测覆盖”后，已知的坏组合不会再被选回。

要注意的限制

“没有 C”是按同一个指标反复挑选出来的，不是方法本身让 C 不可能出现。证据是：每一轮重选后实测仍然出现 1–3 个 C，预测一直比实测乐观。最终这 96 管没有被一个独立的指标验证过，只是在我定的这套阈值下达标。

结论

继续用同样的“选择 → 实测 → 修复”循环，A 级只会小幅增长：第 2 轮到第 3 轮，A 从 61 升到 63。真正的上限由那一对引物决定。这个引物对在 16S-A2-R.1 无尾巴时的 3′端 ΔG 只有约 −0.2，是尾巴引入的，在 96 管里有 23 管低于 −4.5。

最有效的做法是改引物设计而不是继续挑条形码：

  • 替换或微调 16S-A2-R.1 或 16S-A6-F.2 的特异部分。这一条已经评估过，见下一节“后期调整预案”：只改 16S-A2-R.1 的一个碱基，A 级从 63 升到 80（整管实测），但覆盖率和脱靶有代价。
  • 让第三阶段把这一对的 3′端项单独作为硬约束，在选 i5 / i7 时直接排除会让它低于 −4.5 的尾巴。代价是候选池会变小，每周期配色更难满足，可能需要把池扩大。
  • 扩大候选池（比如 144 → 200）：A 的上限不会明显变，因为瓶颈在这对引物；而计算量约 2 倍，在这个沙箱里要十几个小时。
  • 放宽阈值能让 A 变多，但那只是改了标签，不是改进。

引物调整：只改一条引物，不换 UDP（已采用 v4）

已决定采用：最终订购清单是 primer_order_6amp_pool33_v4.xlsx，只改 16S-A2-R.1 一个碱基，UDP 和其余 32 条引物都不动；v3 保留作回退和不加 UDP 时使用。用 v4 引物池把最终 96 管整管重算，结果是 A 80 / B 16 / C 0，核心 48 对 A 38 / B 10 / C 0。

为什么是这一对

16S-A2-R.1 的 3′端 …TAGCC[A/G] 与 16S-A6-F.2 的 5′端 GGCTA… 有 5 个碱基互补。无尾巴时这对的 3′端 ΔG 约为 +0.2，几乎没有相互作用；尾巴的末位碱基正好补上第 6 个配对，才把它拉到 −4.5 以下。所以这是尾巴引入的新问题，原引物池里并不存在。

采用：16S-A2-R.1 第 15 位 A→T（GCTGGCACGKARTTTGCCR）

  • A 级从 63 升到 80，没有 C 级。
  • 长度和展开数（8）不变，Tm 从 64.6 变为 65.7，这条引物本来就偏高。
  • 人基因组脱靶没有增加（28 → 21），猪基因组增加到约 1.9 倍（11 → 21）。
  • 位点覆盖率下降约 4 个点，因为在第 15 位人为引入了一个错配；该位置离 3′端第 5 个碱基，在 3′端 3 nt 之外，通常可耐受，但引物在对应模板上的引发效率可能略降，这一点计算评估不到。

回退条件

  • 触发条件：实验里 A2 或 A6 扩增子的产量、覆盖到的物种比 v3 明显更差（覆盖率下降约 4 个点是预期内），或猪样品的宿主背景明显增多。
  • 操作：把 16S-A2-R.1 换回 v3 序列（GCTGGCACGKARTTAGCCR），重订一条。其余 32 条和全部 UDP 不变。
  • 如果 v3 和 v4 没有差别：保留 v4（A 级更多），继续排查别的原因，例如 A4-R × A5-F.1 这组全局二聚体。

这个改动没有验证的

  • A / B / C 是我定的经验阈值，80 A 不等于产量提高。
  • 覆盖率是在 SILVA 和 Greengenes 上用“≤1 错配且 3′端 3 nt 无错配”的口径算的，没有实验验证引发效率。
  • 其他位点（A4-R × A5-F.1 等）的相互作用没有处理，后期还可能出现。
  • v4 订购清单已生成（只改了这一条）；是否真正订购由你决定，v3 保留作回退。

没有做的事

  • 没有实验验证。A / B / C 不等于测序性能。Illumina 序列有长期的使用积累，自建序列没有；你之前测过 UDP0017 测序量低，这类问题我的评估看不到。
  • 没有评估真实接头，只评估了尾巴加特异部分。
  • 和 Illumina 的 A 级比较不是同条件对比：自建从 960 条里挑，且只对跨类反向互补放宽到 ≥3；Illumina 是固定的 384 对。
  • 建议做一个小对照：同一个样品、多个不同条形码，看测序量差异，再决定要不要继续优化。
