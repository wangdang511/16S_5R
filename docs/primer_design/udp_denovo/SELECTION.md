# 从自建 480 对 UDP 中选 48 / 96 组：逻辑与代码

## 输入
- 480 个候选管：`data/dn480.json`（i5、i7 各 480 条；第 k 个管 = DN{k:03d}，名称 i5 = DN5{k:03d}、i7 = DN7{k:03d}）。
- 每个管的整管评估：`python_5R/explore/udp_tail_eval.py`（33 条引物池，60 个正向、138 个反向展开序列；i5 加在所有正向、i7 加在所有反向引物 5′端；primer3 58 °C，50 mM Na⁺ / 2 mM Mg²⁺ / 0.2 mM dNTP / 250 nM；全部 198×198 两两异源二聚体、3′端锚定、发夹，和 Olivar 总坏度）。

## 分级（经验阈值，没有文献依据；无尾巴基线为 −5.7 / −3.8）
- A：全局二聚体最差 ΔG ≥ −7 且 3′端锚定最差 ≥ −4.5 kcal/mol
- B：≥ −8.5 且 ≥ −5.5
- C：其余
480 个管：A 94、B 171、C 215。

## 选择（`python_5R/explore/udp_dn_select_fast.py`）
硬约束（独立用 `udp_dn_export.py` 重新验证）：
1. 所选 i5 ∪ i7 两两 Levenshtein ≥4；
2. 所选序列之间，x 与 rc(y) 的编辑距离也 ≥4（含同一管里的 i5 与 i7，4 个管 DN144/DN301/DN374/DN453 因此被排除）；
3. 每个周期（第 1–10 位）：GC、A+C、A+T 占比 40–60%，A/C/G/T 各 ≥15%；i5、i7 各自满足。
软目标：A 级尽量多（B 代价 3、C 代价 30 或更高）、二聚体越弱越好。
算法：模拟退火。状态 = N 个管；一次交换一个管；增量计算冲突数（480×480 冲突矩阵 `conflict_T480`，由编辑距离和反向互补距离预先算好）和每周期配色越界量；能量 = 1000×冲突 + 1000×越界平方和 + 分级代价。
结果：48 组 = 28 A + 20 B，冲突 0，越界 0（独立验证：最小编辑距离 4、最小反向互补 4）。

## 为什么不是全 A
A 级管只有 94 个；全 A 子集在冲突和每周期配色约束下凑不出 48 个（试验：75 个 A 里选 48 个，冲突 26、越界 766）。
